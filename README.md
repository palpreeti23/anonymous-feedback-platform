# CipherTalk 🔐

CipherTalk is an anonymous feedback platform that allows users to receive honest messages and feedback through a unique shareable link without revealing the sender's identity.

## ✨ Features

- 🔐 User authentication & email verification
- 💬 Anonymous message sharing
- 🔗 Unique personal feedback links
- 📩 View and manage received messages
- 🛡️ Privacy-focused messaging
- 📱 Responsive UI

## 🛠️ Tech Stack

**Next.js · React · TypeScript · Tailwind CSS · MongoDB · Mongoose · Auth.js**
